1 gVisor sandbox per agent

Control on a Vultr Cloud Compute VM gives each agent a fresh container with no API keys inside, then removes it.

  • 1 GiB memory, 0.75 CPU and 256 processes
  • 120 seconds and 15 steps per agent
  • One way out: an egress proxy with an allowlist
